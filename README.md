# Mexican Train Dominoes

A complete implementation of the classic Mexican Train Dominoes game featuring both a console application and a JavaFX graphical user interface. The project was designed using object-oriented principles with a modular architecture that separates game logic from the user interface, allowing both versions to share the same core functionality.

---

## Features

- Complete Mexican Train Dominoes game
- Console-based version
- JavaFX graphical user interface
- Human and AI players
- Configurable player count (up to 4 players)
- Mixed human/computer gameplay
- Full game rule implementation
- Boneyard draw mechanics
- Train opening and management
- Round scoring and winner determination

## Running the Project

Two versions of the game are included:

### Console Version

Run:

```bash
java -jar console_V4.jar
```

### JavaFX GUI Version

Run:

```bash
java -jar GUI_V7.jar
```
